## 🌟 Overview

FeedSure 360 is a startup-grade, full-stack intelligence platform engineered for dairy farmers. It combines rapid feed testing, computer vision visual screening, real-time silage storage telemetry, evidence-aware AI safeguards, dairy ration evaluation, and cryptographic batch traceability.

---

## 🛑 Hardware Independence Notice

> **IMPORTANT**: This prototype runs **100% software-simulated hardware** with **ZERO physical hardware dependencies** (no ESP32, Arduino, Raspberry Pi, or physical NIR spectrometer required for demo). All hardware inputs are software-generated by a dedicated simulation service and clearly labeled as `PROTOTYPE SIMULATION` / `SIMULATED DEVICE`. The architecture maintains clean modular device adapters for future physical device integration.

## 🏗️ Architecture & Core Intelligence Levels

### Level 1 — What is in the feed?
- **Nutritional Parameters**: Dry Matter (DM %), Moisture %, Crude Protein (CP %), NDF %, ADF %.

### Level 2 — Can we trust the result? (Evidence Engine)
- Evaluates 5 multi-source evidence factors:
  1. **Spectral Quality**: Baseline signal-to-noise ratio.
  2. **Sample Consistency**: Standard deviation across 5 core sampling points.
  3. **Calibration Fit**: Mahalanobis distance check against validated domain.
  4. **Prediction Uncertainty Band**: Ensemble variance / confidence band.
  5. **Visual Screening Agreement**: CV camera anomaly detection.
- **Outcomes**: `TRUSTED` | `RESULT NOT TRUSTED` | `RETEST RECOMMENDED` | `SUSPECTED ADULTERATION` | `STORAGE ALERT`.

### Level 3 — What does it mean for this dairy farm?
- Integrates actual measured feed quality into daily dairy ration formulation for lactating and dry cattle groups.
- Detects crude protein deficits & fiber balance issues.

## 🚀 Quick Start Guide

### 1. Backend (Python FastAPI)
```bash
cd backend
python -m pip install -r requirements.txt
python -m uvicorn main:app --port 8000 --reload
```
FastAPI server will run at: `http://localhost:8000`  
Health check: `http://localhost:8000/api/health`

### 2. Frontend (Next.js 14 + Tailwind CSS + Framer Motion)
```bash
cd frontend
npm install
npm run dev
```
Open `http://localhost:3000` in your browser.

## 🔒 Security, RBAC & Digital Twin Passport
- **Authentication**: JWT token authentication with PBKDF2-HMAC-SHA256 password hashing.
- **Role-Based Access Control (RBAC)**: Distinct permissions for Dairy Farmer, Extension Field Officer, Nutritionist, QA Lab, and Admin.
- **Feed Digital Twin**: Tracks lifecycle (`TEST → STORE → MONITOR → RETEST → USE`).
- **Quality Passport**: Hashed using **SHA-256** for immutable audit trails, paired with an on-screen SVG QR code for instant mobile verification.

## 📡 Smart Feed Zone IoT Node (Barn-Mounted)

- Powered by simulated **ESP32 + SHT31/DHT22 + HX711 load cell** node architecture under ₹1,850 INR target BoM.
